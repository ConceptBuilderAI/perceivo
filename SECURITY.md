# Security Policy

We take the security of Perceivo and its users seriously. Thank you for helping keep the project and
its community safe.

## Supported Versions

Security fixes are provided for **the latest minor release of the latest major version** on PyPI
only. Older minor and major lines do not receive fixes; upgrade to the latest release.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull
requests.**

Instead, report them responsibly using either of the following:

- **Email:** **security@perceivo.ai** (PGP available on request)
- **GitHub:** open a private advisory via the repository's **Security → Report a vulnerability**
  ([GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability))

When reporting, please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce (proof-of-concept code, requests, or a minimal example)
- Affected versions and environment details
- Any suggested remediation

## Our Commitment

- We will acknowledge your report within **3 business days**.
- We will provide an assessment and expected timeline within **10 business days**.
- We will keep you informed of progress toward a fix.
- We will credit you in the release notes and any advisory, unless you prefer to remain anonymous.

## Disclosure Policy

We follow a coordinated disclosure process. Please give us a reasonable opportunity to investigate
and release a fix before any public disclosure. We aim to resolve confirmed high-severity issues
promptly and will coordinate a disclosure timeline with you.

## Scope

This policy covers the code in this repository. Vulnerabilities in the hosted Perceivo platform or
its APIs should also be reported to **security@perceivo.ai**.
